# Info
- Originally made for Chaotic Neutral server
- Minecraft 1.21.10
- Built using [beet](https://mcbeet.dev/)

This pack was created for a community server around December 2025. It was being developed live with server progression, some features were  locked behind non-vanilla systems, so they are unavailable and also balance might be off. On large scale the blight is horribly unoptimized, but I did my best to minimize the TPS lag. Also functions are a mess.
